# Interação Humano-Computador (IHC)

Repositório dedicado aos projetos e atividades desenvolvidos durante a disciplina de **Interação Humano-Computador (IHC)**, no curso de Engenharia da Computação do **Centro Universitário Salesiano de São Paulo (UNISAL)**.

O objetivo deste repositório é reunir aplicações práticas dos conceitos estudados na disciplina, explorando princípios de usabilidade, acessibilidade, design de interfaces e experiência do usuário (UX).

---

## 📚 Sobre a disciplina

A disciplina de Interação Humano-Computador aborda os princípios, métodos e tecnologias envolvidos na concepção, avaliação e desenvolvimento de sistemas interativos.

Entre os principais conceitos estudados estão:

- Usabilidade e experiência do usuário (UX).
- Design de interfaces e interação.
- Acessibilidade digital.
- Arquitetura da informação.
- Avaliação e testes de usabilidade.
- Comportamento e necessidades dos usuários.

## 1. Sebo Nossa Alegria

Website desenvolvido como atividade avaliativa da disciplina de IHC. O projeto consiste em uma plataforma fictícia para comercialização de livros e revistas, aplicando conceitos de design de interfaces e interação com o usuário.

**Tecnologias utilizadas:**

- JavaScript

- **Temas Dark e Light:** Alternância entre os modos claro e escuro.
- **Sistema de comentários:** Possibilidade de registrar comentários e avaliações sobre os produtos.
- **Sistema de perfil:** Criação de perfis personalizados para os usuários.
- **Sistema de frete:** Funcionalidade para estimar os custos de entrega dos pedidos.

## 2. Post-it

Projeto de interface inspirado nos tradicionais blocos de notas adesivas, com a proposta de organizar informações e facilitar o registro de lembretes e tarefas em um ambiente digital.

A aplicação explora conceitos de organização visual, simplicidade e interação direta, buscando proporcionar uma experiência intuitiva para o usuário.

### Funcionalidades e conceitos de IHC

- **Organização visual:** Distribuição das anotações em uma interface inspirada em post-its físicos.
- **Identificação por cores:** Utilização de cores para diferenciar e organizar informações.
- **Facilidade de interação:** Proposta de uma interface simples, com elementos visuais de fácil compreensão.
- **Hierarquia da informação:** Organização dos conteúdos para facilitar a identificação dos lembretes.
- **Feedback visual:** Uso de elementos visuais para indicar ações e alterações realizadas pelo usuário.

## 3. Tela de Login

Projeto de desenvolvimento de uma interface de autenticação, com foco na interação entre usuário e sistema durante o processo de acesso.

A proposta explora princípios de simplicidade, clareza e organização dos elementos de interface, tornando o processo de identificação mais compreensível e acessível.

### Funcionalidades e conceitos de IHC

- **Campos de entrada:** Organização dos campos destinados ao preenchimento das credenciais.
- **Identificação dos elementos:** Utilização de rótulos e indicações para orientar o preenchimento.
- **Feedback de interação:** Indicação visual das ações realizadas pelo usuário.
- **Prevenção de erros:** Organização dos campos para reduzir possíveis erros durante o preenchimento.
- **Hierarquia visual:** Destaque dos elementos principais, como campos de acesso e botão de autenticação.
- **Consistência visual:** Padronização dos elementos para proporcionar uma experiência de navegação coerente.

## 4. Futebol Blog

Projeto de interface para um blog com temática relacionada ao futebol, explorando a apresentação e organização de conteúdos informativos em uma plataforma digital.

A proposta considera a experiência de navegação do usuário, a organização das informações e a facilidade de acesso às publicações.

### Funcionalidades e conceitos de IHC

- **Organização de conteúdo:** Distribuição das informações em seções para facilitar a leitura.
- **Hierarquia da informação:** Destaque para títulos, notícias e conteúdos relevantes.
- **Navegação intuitiva:** Organização dos elementos de navegação para facilitar o acesso às diferentes áreas do blog.
- **Apresentação visual:** Utilização de elementos gráficos relacionados à temática esportiva.
- **Legibilidade:** Organização de textos, títulos e imagens para melhorar a experiência de leitura.
- **Consistência da interface:** Padronização dos componentes visuais e da estrutura das páginas.

# 🎓 Aprendizados

O desenvolvimento das atividades proporcionou a aplicação prática dos conceitos estudados em Interação Humano-Computador.

Entre os principais aprendizados, destacam-se:

- **Usabilidade:** A importância de desenvolver interfaces fáceis de aprender e utilizar.
- **Experiência do usuário (UX):** A compreensão de como as decisões de design influenciam a satisfação e a experiência durante a utilização de um sistema.
- **Feedback:** A necessidade de fornecer respostas visuais às ações realizadas pelos usuários.
- **Consistência:** A importância de manter padrões visuais e comportamentais entre os elementos de uma aplicação.
- **Prevenção e tratamento de erros:** A utilização de recursos que ajudam a evitar erros e orientam o usuário quando eles acontecem.
- **Acessibilidade:** A necessidade de considerar diferentes usuários e suas necessidades durante o desenvolvimento de interfaces.
- **Arquitetura da informação:** A importância de organizar conteúdos e funcionalidades de maneira lógica e compreensível.
- **Design centrado no usuário:** A compreensão de que o desenvolvimento de sistemas deve considerar as necessidades, limitações e expectativas das pessoas que irão utilizá-los.

# 📖 Leituras e recursos recomendados

Algumas referências importantes para aprofundar os conhecimentos em IHC e design de interfaces:

1. **The Design of Everyday Things** — Donald Norman.
2. **Don't Make Me Think** — Steve Krug.
3. **Designing Interfaces** — Jenifer Tidwell.
4. **Interaction Design: Beyond Human-Computer Interaction** — Preece, Rogers e Sharp.
5. **[Nielsen Norman Group](https://www.nngroup.com/)** — Artigos, pesquisas e materiais sobre usabilidade e experiência do usuário.
6. **[Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)** — Diretrizes de design de interfaces da Apple.
7. **[Google Material Design](https://m3.material.io/)** — Sistema de design e diretrizes de interface do Google.
